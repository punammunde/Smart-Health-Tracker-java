# 🩺 Smart Health Tracker (Java)

An automatic health tracking application developed using Java.
It simulates daily health activities without manual input.

## 🚀 Features
- Automatic step tracking
- Calories burned calculation
- Water intake recommendation
- Activity status detection
- Hydration status monitoring

## 🛠️ Technologies Used
- Java
- OOP Concepts
- Random Class

## 📊 Calculation Logic
- Steps are auto-generated (3000–12000)
- Calories = Steps × 0.04
- Water intake based on activity level
